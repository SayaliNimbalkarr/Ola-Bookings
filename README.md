# Ola Bookings Analysis Dashboard

## Overview

This project analyzes an Ola Bookings dataset containing 100,000 records. The workflow includes data cleaning, SQL-based analysis, and dashboard creation to generate business insights.

## Tools Used

* Python (Pandas)
* PostgreSQL
* Power BI

## Project Workflow

### 1. Data Cleaning with Python

* Checked data formats and structure
* Handled missing/null values
* Identified and checked duplicate records

### 2. Database Management

* Imported the cleaned dataset into PostgreSQL
* Performed SQL queries to answer business-related questions

### 3. Dashboard Development

* Connected PostgreSQL to Power BI
* Created an interactive dashboard to visualize key metrics and trends

## Key Insights

* Booking performance analysis
* Customer, driver and vehicle-type trends
* Revenue-related metrics
* Booking status distribution

## Dataset

* Ola Bookings Dataset
* Records: 100,000
